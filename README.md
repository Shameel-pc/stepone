## how to use 

1. put the image to be  generated and and the python file in the same folder
2. run the program and enter the file name (including extension)
3. the ascii art is printed into the terminal

## Tips
sometime to aprreate an art you have to look from a wider view
- so to see this art you may have to lower you magnification a little (some time not so little)
- if the image is not forming clearly you can increase the resolution by increasing the image width from the code
- also you can change the thresold where the boundary of the pixel charectoer changing the variables a,b,.....,i,j
